# Vanilla Bug Fixes

RimWorld mod that fixes small bugs in the base game's code. Every fix can be switched on or off in the mod settings. No defs, numbers or balance are changed.

## Requirements

- RimWorld 1.6 or 1.7
- [Harmony](https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077)

## Building

Needs the .NET 10 SDK. Run `Source/Build.ps1` from a checkout inside `RimWorld/Mods/<any folder>/Source/`. It builds both game versions and copies the mod to `RimWorld/Mods/VanillaBugFixes`.
